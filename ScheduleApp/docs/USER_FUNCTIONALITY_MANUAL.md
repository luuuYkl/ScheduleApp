## 🚀 产品概述

ScheduleApp 是一个现代化的 **AI 驱动的习惯追踪和日程管理应用**，专为长期目标管理和日常任务执行而设计。

### 核心理念

- **计划不是进度追踪，而是方向确认** - 弱化百分比，强调阶段感
- **事件型思维 vs 任务型思维** - 日程强调时间，任务强调完成
- **移动优先，响应式自适应** - 完美支持桌面和移动端

### 主要功能

| 功能模块 | 说明 | 状态 |
|---------|------|------|
| 📈 计划管理 | 长期目标规划，AI 智能建议 | ✅ 完成 |
| ✅ 任务管理 | 日常任务创建、重复任务、进度追踪 | ✅ 完成 |
| 📅 日程管理 | 事件提醒、快捷创建 | ✅ 完成 |
| 📊 日志分析 | AI 驱动的任务分析和建议 | ✅ 完成 |
| 🎨 主题系统 | 暗色/明亮双模式 | ✅ 完成 |
| 👤 用户系统 | 注册登录、头像管理 | ✅ 完成 |

## 🛠️ 快速开始

### 1. 环境要求

```bash
Node.js >= 18.0.0
npm >= 9.0.0
```

### 2. 安装与启动

```bash
# 克隆项目
git clone https://github.com/luuuYkl/ScheduleApp.git
cd ScheduleApp

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5173

### 3. AI功能配置（可选）

如果需要使用真实的AI功能，创建 `.env` 文件：

```bash
cp .env.example .env
```

编辑 `.env` 文件，填入你的API Key：

```env
VITE_DEEPSEEK_API_KEY=your_api_key_here
```

> ⚠️ **注意**: 默认使用Mock数据，不需要API Key即可运行。

## 🎨 核心功能使用指南

### 1. 计划管理

#### 创建新计划
1. 点击首页"新建计划"按钮
2. 填写计划基本信息：
   - 标题（必填）
   - 描述（可选）
   - 开始日期和结束日期
3. 可选择使用AI智能优化功能

#### AI智能优化
**功能亮点：**
- 分析计划的合理性
- 提供时间安排建议
- 自动拆解任务清单
- 优化计划标题和描述

**使用步骤：**
1. 填写计划基本信息
2. 点击 **🤖 AI 智能优化** 按钮
3. 等待AI分析（通常3-5秒）
4. 查看AI提供的建议和推荐任务清单
5. 选择性应用优化建议

### 2. 任务管理

#### 创建任务
1. 进入计划详情页面
2. 点击"添加任务"
3. 设置任务信息：
   - 任务标题
   - 执行日期
   - 预估时长
   - 优先级

#### 任务状态管理
- ✅ **待完成** - 默认状态
- ✅ **已完成** - 勾选后自动标记
- ⏰ **已错过** - 超过截止日期未完成

#### 重复任务
支持设置周期性重复任务：
- 每日重复
- 每周重复
- 每月重复
- 自定义间隔

### 3. 日程管理

#### 创建日程
1. 点击底部导航"日程"图标
2. 点击"+"按钮创建新日程
3. 设置日程信息：
   - 事件标题
   - 时间安排
   - 提醒设置
   - 重复规则
   - 地点和备注

#### 日程提醒
- 支持多种提醒方式
- 可设置提前提醒时间
- 重复事件的智能提醒

### 4. 日志分析

#### 自动日志生成
当您完成任务时，系统会：
- ✅ 自动检测今天的任务
- ✅ 自动生成/更新当日日志
- ✅ 在控制台输出确认信息

#### 查看日志
1. 点击底部导航"日志"图标
2. 查看历史日志记录
3. AI会提供智能分析和建议

#### 日志特色
- 📅 智能日期显示（今天/昨天/具体日期）
- 📊 完成度颜色标识
  - 🟢 绿色：≥80%
  - 🟠 橙色：50-79%
  - 🔴 红色：<50%
- 🔄 实时刷新功能
- ➕ 手动生成选项

## 🔍 故障排除

### 常见问题

#### Q1: AI功能无法使用
**解决方案：**
1. 检查是否配置了有效的API Key
2. 确认网络连接正常
3. 查看浏览器控制台错误信息
4. 可暂时使用Mock模式进行测试

#### Q2: 页面布局显示异常
**解决方案：**
1. 刷新页面
2. 清除浏览器缓存
3. 检查屏幕分辨率设置
4. 尝试不同的浏览器

#### Q3: 数据丢失问题
**解决方案：**
1. 检查浏览器存储权限
2. 使用数据导出功能备份
3. 访问存储清理页面重置数据

#### Q4: 主题切换不生效
**解决方案：**
1. 确认已正确选择主题模式
2. 检查是否有浏览器扩展干扰
3. 重启应用或清除缓存

### 调试工具

#### 开发者工具
- 浏览器控制台查看错误信息
- 网络面板监控API请求
- 应用存储查看本地数据

#### 内置调试页面
访问以下特殊页面进行调试：
- `http://localhost:5173/clear-storage.html` - 存储清理工具
- `http://localhost:5173/theme-test.html` - 主题测试页面

## 🎯 最佳实践建议

### 计划制定建议
1. **明确目标**：计划标题要具体明确
2. **合理时间**：设置切实可行的时间范围
3. **分解任务**：将大目标拆解为小任务
4. **定期回顾**：利用AI分析优化计划

### 任务管理技巧
1. **优先级排序**：重要紧急任务优先处理
2. **时间估算**：合理评估任务所需时间
3. **及时完成**：避免任务积压和拖延
4. **记录反思**：通过日志总结经验教训

### 习惯养成策略
