# ADR-001：双端统一 Bridge 版本治理

- 状态：Accepted
- 日期：2026-02-10

## 背景
Android 与 Harmony NEXT 并行开发时，Bridge 接口容易产生平台分叉，导致 H5 适配成本上升。

## 决策
1. 统一采用 `bridge-v1.contract.json` 作为单一契约源。
2. Bridge 能力新增遵循“先能力声明，再功能依赖”的顺序。
3. 兼容策略：
   - 小改动（向后兼容）升级次版本。
   - 不兼容改动升级主版本，并保留上一主版本最少一个发布周期。

## 影响
- 正向：降低跨端分叉风险，提高验收一致性。
- 负向：平台团队需要先同步契约再开发，初期节奏略慢。
