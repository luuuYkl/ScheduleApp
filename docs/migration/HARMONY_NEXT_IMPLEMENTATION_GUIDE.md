# Harmony NEXT 迁移实施指南（Phase 1~2）

## Phase 1：壳工程最小可用

1. 创建 Stage 模型应用壳
2. Web 组件加载 H5（支持环境配置）
3. 网络访问策略与白名单配置
4. 接入 JS Bridge V1（与 Android 保持同协议）

## Phase 1 验收

- 冷启动进入首页
- 登录态可安全持久化
- 计划/任务/日志/AI 功能可用
- 关键错误可采集

## Phase 2：稳定性与性能

1. 生命周期与状态恢复
2. 路由切换与列表性能优化
3. 弱网与离线提示
4. 异常上报与埋点接入

## 发布前检查

- 应用签名与分发材料齐备
- 权限与隐私说明完整
- 双端协议兼容测试通过
