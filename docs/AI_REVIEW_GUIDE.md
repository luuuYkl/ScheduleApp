# AI 复盘功能使用指南

## 功能概述

AI 复盘功能使用 DeepSeek AI 模型对你的任务完成情况进行智能分析和总结，支持三个时间维度的复盘：

- **今天**：当日的任务完成情况分析
- **本周**：一周内的工作总结和坚持度评估  
- **本月**：整月的生产力趋势分析

## 功能特性

### 📊 三大核心指标

1. **完成率** (0-100%)
   - 计算周期内完成的任务比例
   - 包含已完成 (done) 和未完成 (pending/missed) 的任务

2. **生产力评分** (0-100)
   - 基于完成率和任务数量
   - 反映你的整体产出效率

3. **坚持度评分** (0-100)
   - 按日期统计每天的完成情况
   - 衡量你的日常持续性

### 💡 智能分析内容

每份复盘包含：
- **总结**：简洁的周期总结（2-3句）
- **关键洞察**：3个重要发现
- **改进建议**：3个可行的优化建议

## 使用方法

### 1. 前置条件

确保你已经：
- 创建了任务并标记完成状态
- 拥有有效的 DeepSeek API 密钥

### 2. 配置 API 密钥

在 `.env.local` 文件中设置：

```env
VITE_OPENAI_API_KEY=your-deepseek-api-key-here
```

### 3. 生成复盘

在日志页面 (Log) 中：

1. 选择要复盘的时间维度（今天/本周/本月）
2. 点击"生成复盘"按钮
3. 等待 AI 分析完成
4. 查看详细的复盘报告

### 4. 理解复盘数据

#### 完成率示例
- **90-100%**：优秀，保持这个势头！
- **70-89%**：良好，再接再厉
- **50-69%**：中等，需要改进
- **0-49%**：较低，建议调整计划

#### 生产力评分解读
分数反映你在该时间周期内的综合生产力表现，包括完成率和任务复杂度。

#### 坚持度评分解读
高分表示你在该周期内的日常任务完成比较稳定，低分表示完成情况波动较大。

## 技术架构

### 核心文件

1. **服务层** (`src/services/ai-review.ts`)
   - 与 DeepSeek API 通信
   - 数据计算和指标生成
   - Mock 数据支持

2. **状态管理** (`src/store/ai-review.ts`)
   - 管理复盘数据状态
   - 支持 localStorage 持久化
   - 加载、生成、清空复盘

3. **UI 组件** (`src/components/log/AIReviewPanel.vue`)
   - 复盘展示界面
   - 时间维度切换
   - 指标可视化

4. **页面集成** (`src/pages/Log/LogPage.vue`)
   - 集成 AI 复盘面板
   - 与日志系统配合

### API 集成

**请求流程：**
```
用户点击 → 收集任务数据 → 构建 Prompt 
→ 调用 DeepSeek API → 解析响应 → 显示复盘
```

**Fallback 机制：**
- API 调用失败 → 使用 Mock 数据
- 无 API 密钥 → 使用 Mock 数据
- 保证应用可用性

## 数据流

```
LogPage (日志页面)
    ↓
AIReviewPanel (复盘面板)
    ↓
useAIReviewStore (状态管理)
    ↓
generateAIReview() (AI 服务)
    ↓
callDeepSeekAPI() (API 调用)
    ↓
显示复盘结果 → localStorage 持久化
```

## 常见问题

### Q: 为什么看不到复盘数据？
**A:** 检查：
1. 是否有任务数据
2. API 密钥是否正确配置
3. 网络连接是否正常
4. 检查浏览器控制台是否有错误

### Q: 可以离线使用吗？
**A:** 可以。没有 API 密钥时会使用 Mock 数据生成默认复盘。

### Q: 复盘数据会保存吗？
**A:** 会。复盘数据会保存到 localStorage，页面刷新后可以恢复。

### Q: 如何清除复盘数据？
**A:** 在浏览器中清除网站数据或手动删除 localStorage 中的 `ai-reviews-{userId}` 键。

## 故障排查

### DeepSeek API 连接失败

1. 检查网络连接
2. 验证 API 密钥有效性
3. 查看 API 用量是否超限
4. 检查浏览器控制台错误信息

### 复盘内容显示异常

1. 清除浏览器缓存
2. 硬刷新页面 (Ctrl+Shift+R)
3. 检查浏览器控制台是否有 TypeScript 错误
