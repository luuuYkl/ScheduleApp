# 全局颜色系统升级指南

## 🎨 六层颜色架构

### 1. Brand 层（品牌主色）
```css
--color-brand-500: #6366F1;  /* 主品牌色 - 主按钮 */
--color-brand-600: #4F46E5;  /* Hover/Active 状态 */
--color-brand-400: #818CF8;  /* 浅色高亮 */
--color-brand-100: #E0E7FF;  /* 轻背景 */
--color-brand-alpha-12: rgba(99, 102, 241, 0.12);  /* 浅高亮面 */
--color-brand-alpha-24: rgba(99, 102, 241, 0.24);  /* 边框/焦点环 */
```

### 2. Neutral 层（中性色系统）
**暗色主题：**
```css
--color-bg-page: #0E1117;        /* 页面背景 */
--color-bg-card: #161B22;        /* 卡片背景 */
--color-bg-elevated: #21262D;    /* 抬升层 */
--color-bg-input: #0D1117;       /* 输入框背景 */

--color-text-primary: #E5E7EB;   /* 主文本 */
--color-text-secondary: #9CA3AF;  /* 次文本 */
--color-text-muted: #6B7280;     /* 说明文本 */

--color-border-primary: rgba(255, 255, 255, 0.08);  /* 主边框 */
--color-border-subtle: rgba(255, 255, 255, 0.04);   /* 细边框 */
```

**浅色主题：**
```css
--color-bg-page: #F5F5F5;     /* 页面背景 */
--color-bg-card: #FAFAFA;     /* 卡片背景 */
--color-bg-elevated: #F0F0F0; /* 抬升层 */
--color-bg-input: #FFFFFF;    /* 输入框背景 */

--color-text-primary: #0F172A;   /* 主文本 */
--color-text-secondary: #475569; /* 次文本 */
--color-text-muted: #94A3B8;     /* 说明文本 */

--color-border-primary: rgba(15, 23, 42, 0.10); /* 主边框 */
--color-border-subtle: rgba(15, 23, 42, 0.05);  /* 细边框 */
```

### 3. Semantic 层（语义色）
```css
--color-success: #22C55E;  /* 成功状态 */
--color-success-bg: rgba(34, 197, 94, 0.12);

--color-warning: #F59E0B;  /* 警告状态 */
--color-warning-bg: rgba(245, 158, 11, 0.12);

--color-error: #EF4444;    /* 错误状态 */
--color-error-bg: rgba(239, 68, 68, 0.12);

--color-info: #3B82F6;     /* 信息状态 */
--color-info-bg: rgba(59, 130, 246, 0.12);
```

### 4. Surface 层（组件表面）
```css
--color-surface-card-hover: #1C2128;  /* 暗色主题卡片悬停 */
--color-surface-card-hover: #F0F0F0;  /* 浅色主题卡片悬停 */
```

### 5. Interactive 层（交互状态）
```css
--color-interactive-hover: var(--color-brand-600);
--color-interactive-active: var(--color-brand-600);
--color-focus-ring: var(--color-brand-alpha-24);
```

## 🎯 组件颜色映射

### 按钮组件
```css
/* Primary Button */
background: var(--color-brand-500);
color: white;
:hover { background: var(--color-brand-600); }

/* Secondary Button */
background: var(--color-bg-card);
border: 1px solid var(--color-border-primary);
color: var(--color-text-primary);
:hover { background: var(--color-surface-card-hover); }

/* Ghost Button */
background: transparent;
color: var(--color-text-secondary);
:hover { background: var(--color-brand-alpha-12); }
```

### 输入框组件
```css
background: var(--color-bg-input);
border: 1px solid var(--color-border-primary);
:focus {
  border-color: var(--color-brand-500);
  box-shadow: 0 0 0 3px var(--color-brand-alpha-24);
}
```

### 卡片组件
```css
background: var(--color-bg-card);
border: 1px solid var(--color-border-subtle);
:hover { background: var(--color-surface-card-hover); }
```

### 顶栏/底栏玻璃态
```css
/* 暗色主题 */
background: var(--color-glass-dark);  /* rgba(13, 17, 23, 0.72) */

/* 浅色主题 */
background: var(--color-glass-light); /* rgba(250, 250, 250, 0.82) */
```

## 🔄 向后兼容性

原有变量已通过映射保持兼容：
```css
--bg-main → --color-bg-page
--bg-card → --color-bg-card
--text-main → --color-text-primary
--ai-main → --color-brand-500
--success → --color-success
```

## ✅ 使用建议

1. **新开发**：优先使用新的语义化变量名
2. **重构**：逐步替换旧变量，保持功能一致
3. **主题切换**：通过 `data-theme` 属性控制
4. **调试**：使用浏览器开发者工具检查变量值
